===============================================================================
          CONEXIÓN FÍSICA: BH1750 ↔ ESP8266 (NodeMCU / Wemos D1 Mini)
===============================================================================

       +-----------------+       I2C       +-------------------+
       |                 |   SDA  GPIO4   |                   |
       |    BH1750       | ◄------------► |     ESP8266       |
       |  (Sensor Luz)   |   SCL  GPIO5   |   (NodeMCU)       |
       |                 | ◄------------► |                   |
       +-----------------+                 +-------------------+
               |   |                            |   |
              VCC  GND                         3.3V GND
               |   |                            |   |
              +|+  +|---------------------------|+  +|

CONEXIONES DETALLADAS:
┌────────────┬─────────┬──────────────────────┐
│ BH1750     │ Pin     │ ESP8266 (NodeMCU)    │
├────────────┼─────────┼──────────────────────┤
│ VCC        │ 3.3V    │ 3.3V                 │
│ GND        │ GND     │ GND                  │
│ SDA        │ Data    │ D2 (GPIO4)           │
│ SCL        │ Clock   │ D1 (GPIO5)           │
│ ADDR       │ GND     │ (Modo 0x23)          │
└────────────┴─────────┴──────────────────────┘

NOTAS:
- Usa resistencias pull-up 4.7kΩ en SDA y SCL (opcional si el módulo ya las tiene)
- ADDR a GND → Dirección I2C: 0x23
- ADDR a VCC → Dirección I2C: 0x5C
